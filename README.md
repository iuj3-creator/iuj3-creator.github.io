# Ira Jadhav Portfolio

A simple responsive personal portfolio website built for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — website design and responsive styling
- `ira-headshot.jpg` — professional headshot
- `Ira-Jadhav-Resume.pdf` — downloadable resume

## Publish with GitHub Pages

1. Sign in to GitHub.
2. Create a new **public** repository. A simple name is `portfolio`.
3. Upload `index.html` and `style.css` to the repository root.
4. Open the repository and go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then click **Save**.
7. Wait a minute or two and refresh the Pages section.
8. GitHub will show your live website URL.

Typical URL:
`https://YOUR-GITHUB-USERNAME.github.io/portfolio/`

## What to submit
- Public GitHub repository link
- Live GitHub Pages website URL

## Before submitting
- Open every navigation link.
- Test the LinkedIn and email buttons.
- Check the site on both desktop and mobile.
- Make sure the repository is public.
- Make sure the GitHub Pages URL loads while signed out of GitHub.
